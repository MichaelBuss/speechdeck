# Three built-in themes: Harbour, Ink, Signal

v0 ships three built-ins as subpaths of `@speechdeck/themes`: Harbour (travelling, iA-ish), Ink (still, noir editorial), Signal (travelling, vibrant P3). `init` and `--yes` write Harbour. A **Deck** still requires `theme:` — Harbour is only the wizard default.

One would force Harbour to also be the P3 look, or drop noir. Four has no talk; the third-party seam already exists. Ink is still because noir editorial is a page, not a sunset. The noir row is Ink, not Noir — ADR 0010 already used `@alice/noir` for anyone's package.
