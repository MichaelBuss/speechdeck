# SpeechDeck

A web-based presentation framework: you write a document, the headings reach the audience, the **Speech** stays with the speaker.

This repo is a pnpm workspace of five JSR packages. The glossary is [`CONTEXT.md`](./CONTEXT.md). Hard-to-reverse calls live in [`docs/adr/`](./docs/adr/).

```sh
pnpm install
pnpm ci
```
